# 国内访问方案：阿里云轻量服务器 + 备案

## 先说清楚现实

- 中国大陆的网站要稳定快速访问，**必须 ICP 备案**，这是行政法规，没有技术绕过的办法。
- 免备案的免费平台（Cloudflare、EdgeOne 全球区、Vercel、GitHub Pages）给你分配的都是境外节点，国内访问要么慢要么不通。你现在遇到的正是这个。
- 备案本身**不花钱**，但需要有阿里云的境内服务器实例才能提交（备案系统要校验"备案服务号"）。
- 所以最省的组合是：一台最便宜的境内轻量服务器 + 免费备案 + Nginx 直接托管。**总成本约 99～300 元/年**。

## 流程（按顺序做，不要跳）

### 1. 域名实名认证

阿里云域名控制台确认 `yujianxiaoquan.online` 实名认证已通过。备案时域名必须是已实名状态，且注册商在工信部白名单内（阿里云符合）。

### 2. 买服务器

阿里云 → 轻量应用服务器 → 地域选**境内**（杭州/北京/上海任选，选离你近的）→ 镜像选 **Ubuntu 22.04** 或 **Debian 12** → 套餐选最低档。

买完记下：公网 IP、root 密码。

### 3. 提交备案

阿里云 → 备案系统 → 首次备案：

- 主体：个人，身份证 + 人脸核验
- 网站信息：网站名称不要用"博客""个人网站"这类泛词，用具体名字（例："子諭的学习笔记"），否则会被驳回
- 服务内容：选"其他"，如实填写
- 域名：`yujianxiaoquan.online`，可以同时把 `www` 加上
- 服务器：选你刚买的那台

审核时间：阿里云初审 1-2 个工作日，管局终审 7-20 个工作日。**备案期间域名不能解析到境内服务器对外访问**，这段时间旧站保持现状即可。

### 4. 服务器初始化（备案通过后做）

```bash
# 登录服务器
ssh root@你的公网IP

# 装 Nginx 和 certbot
apt update && apt install -y nginx certbot python3-certbot-nginx rsync

# 建站点目录
mkdir -p /var/www/yujianxiaoquan.online
```

把 `deploy/nginx.conf` 传到服务器：

```bash
# 本地执行
scp deploy/nginx.conf root@你的IP:/etc/nginx/sites-available/yujianxiaoquan.online
ssh root@你的IP "ln -s /etc/nginx/sites-available/yujianxiaoquan.online /etc/nginx/sites-enabled/ && rm -f /etc/nginx/sites-enabled/default && nginx -t && systemctl reload nginx"
```

### 5. 签发 HTTPS 证书

先确保域名已经解析到服务器 IP（第 6 步），然后：

```bash
certbot --nginx -d yujianxiaoquan.online -d www.yujianxiaoquan.online
```

按提示填邮箱、同意条款即可。certbot 会自动改写 Nginx 配置并设置每 90 天自动续期。

### 6. DNS 解析

如果域名还在 Cloudflare 托管，去 Cloudflare DNS 加：

| 类型 | 名称 | 内容 | 代理状态 |
|---|---|---|---|
| A | `@` | 你的服务器公网 IP | **仅 DNS（灰色云朵）** |
| A | `www` | 你的服务器公网 IP | **仅 DNS（灰色云朵）** |

**必须关掉橙色云朵代理**，否则流量绕道 Cloudflare 境外节点，国内访问又慢了。

或者把 NS 改回阿里云云解析，在阿里云加同样的两条 A 记录——境内服务器建议直接回阿里云管理，少一层。

### 7. 部署网站

改 `deploy/deploy.sh` 里的 `HOST` 为你的服务器，然后本地执行：

```bash
bash deploy/deploy.sh
```

以后每次更新内容，只要跑这一条命令，构建 + 上传 + 重载 Nginx 一条龙。

## 备案常见驳回原因

- 网站名称含"博客""个人""空间"等泛词 → 改成具体名称
- 网站名称与域名含义完全无关 → 备案系统会提示
- 身份证照片反光、边缘不全
- 手机号与主体不一致
- 网站上没有内容（备案审核会访问域名，空站容易驳回）
