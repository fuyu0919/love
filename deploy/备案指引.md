# ICP 备案操作指引（百度智能云 · 个人主体）

面向：`yujianxiaoquan.online`，个人备案，服务器为百度智能云华北-北京轻量云主机。

---

## 一、先自查三条前置条件

| 条件 | 怎么查 | 不满足的后果 |
|---|---|---|
| 域名已完成实名认证 | 阿里云域名控制台 → 域名列表 → 实名认证状态 | 备案系统直接拦截，无法提交 |
| 域名后缀在工信部批复名单内 | `.online` 2017 年已批复 ✓ | —— |
| 服务器购买时长 ≥ 3 个月 | 你买的是 1 年 ✓ | 拿不到备案服务号 |

另外确认：域名注册人姓名与备案主体姓名**完全一致**（都是你本人）。不一致要先过户。

---

## 二、材料清单（提前准备好，省一半时间）

- 身份证正反面照片（清晰、四角完整、不反光、不用美颜）
- 本人手机号（需为本人实名，审核期间保持畅通）
- 常用邮箱
- 现居住地址（精确到门牌号，与身份证地址不同也可以，但要真实）
- 紧急联系人姓名和手机号（一般填家人）

---

## 三、操作步骤

### 第 1 步：进入备案系统

百度智能云控制台 → 搜索「备案」→ 进入 ICP 备案系统 → 「新增备案」→ 选择「首次备案」。

系统会自动带出你名下可用的云资源（那台北京的轻量云主机），选中它作为备案服务资源。

### 第 2 步：填写主体信息

- 主体性质：**个人**
- 姓名、身份证号：与身份证完全一致
- 手机号、邮箱：能收短信、能收邮件
- 通信地址：精确到门牌号
- 上传身份证正反面

### 第 3 步：填写网站信息

这一栏是驳回重灾区，逐项对照：

| 字段 | 填什么 | 注意事项 |
|---|---|---|
| 网站名称 | **子諭的学习笔记** | 别写「博客」「个人网站」「个人空间」这类泛词；不能含「中国」「国家」「政府」等；不能与企业名称混淆 |
| 网站域名 | `yujianxiaoquan.online` | 只填主域名，不要填 www 和路径 |
| 网站服务内容 | 其他 → 个人日志/博客类 | 按实际选，与网站内容一致即可 |
| 网站语言 | 中文简体 | |
| 网站负责人 | 本人 | 与主体一致 |

百度云一般要求填「网站备案信息真实性核验单」，在线电子签署，不需要打印寄送。

### 第 4 步：人脸核验

用百度智能云 App 或微信小程序完成人脸识别。光线充足、摘掉眼镜和帽子，一次过。

### 第 5 步：提交初审

提交后百度云审核 1-2 个工作日。**这段时间会有电话打给你**，号码一般是百度云客服或属地核验号码，务必接听并如实回答（会问网站用途、是否本人操作）。漏接会被退回重来。

### 第 6 步：管局审核

初审通过后自动提交到**北京市通信管理局**，7-20 个工作日。

期间可能收到工信部短信，要求在 24 小时内点击链接完成核验，**必须及时处理**，过期视为放弃。

### 第 7 步：拿到备案号

通过后会收到短信和邮件，备案号形如「京ICP备2026XXXXXX号-1」。

---

## 四、备案期间不能做的事

- **不要把域名解析到这台境内服务器**。未备案域名解析到境内 IP 属于违规，会被要求整改，严重的会被服务商停用
- 不要修改域名的注册人信息、不要过户
- 不要把网站名称改成与企业相关的字样

Cloudflare 上那套部署继续跑着，不影响备案。

---

## 五、常见驳回原因

| 驳回原因 | 怎么改 |
|---|---|
| 网站名称不规范（含「博客」「个人」等泛词） | 改成具体名称，如「子諭的学习笔记」 |
| 网站名称与主体无关 | 名称里带上你的名字或明确的主题 |
| 身份证照片反光/边缘被裁 | 重新拍，白底，四角留边 |
| 手机号非本人实名 | 换成本人实名的号码 |
| 核验电话未接听 | 重新提交，保持手机畅通 |
| 通信地址不详细 | 精确到门牌号 |
| 域名注册人信息与主体不一致 | 先在阿里云完成实名变更 |

---

## 六、备案通过之后还有两件事

### 1. 网站底部挂备案号（强制）

法规要求已备案网站必须在首页底部展示备案号，并链接到 `https://beian.miit.gov.cn/`。

站点已支持：打开 `src/consts.ts`，把 `icp` 字段填上你的备案号：

```ts
icp: '京ICP备2026XXXXXX号-1',
```

重新构建后页脚会自动出现并带链接。留空则不显示。

### 2. 公安联网备案（30 日内）

备案通过后 30 天内，到「全国互联网安全管理服务平台」（`beian.mps.gov.cn`）做公安备案。北京地区执行较严格，别漏。

需要的材料：ICP 备案号、主体信息、网站负责人信息，填写网站服务类型和内容，提交后等审核，通过会给你一个公安备案号，同样需要挂在网站底部。

## 七、时间线参考

| 阶段 | 耗时 |
|---|---|
| 准备材料 | 半天 |
| 填报 + 人脸核验 | 1 小时 |
| 百度云初审 | 1-2 个工作日 |
| 管局审核 | 7-20 个工作日 |
| **合计** | **通常 2-3 周** |

如果被驳回，每次重来会多花 3-7 天。第一次就填对最省时间。
